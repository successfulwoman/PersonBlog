发一篇帖子的完整流程
记住一句话：写 Markdown 文件 → 图片放 public/img → 本地预览 → 构建上线，全程不用碰代码。
1
写文章
在 src/content/blog/ 对应分类目录里新建 .md 文件
→
2
放图片
图片丢进 public/img/，文章里用路径引用
→
3
本地预览
pnpm dev 打开 localhost:4321 检查效果
→
4
生成资产
pnpm koharu generate all 刷新占位图与推荐
→
5
构建上线
pnpm docker:up 或 pnpm build 后部署
文件都放在哪（项目根目录 astro-koharu-6.2.2/）
astro-koharu-6.2.2/
├── src/content/blog/文章放这里
│   ├── daily/ 日常分类文章
│   ├── life/  随笔分类文章
│   ├── tech/  技术分类文章
│   └── _template.md 发帖模板（下划线开头不会被发布，可直接复制）
├── public/img/图片放这里
│   ├── posts/  文章正文图和封面（推荐，命名：文章名.序号.webp）
│   ├── custom/ 头像、站点头图；custom/cover/ 里是 21 张默认封面
│   └── effects/ 站点装饰特效图
├── config/改站点设置
│   └── site.yaml 站名、分类映射、导航、友链等全部配置
└── dist/ pnpm build 自动生成的成品网站，不用手改
